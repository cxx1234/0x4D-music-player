# I18n — 界面本地化

> 本文件记录本地化的目录结构、约定与已知限制。改界面文案前先读一遍。

⸻

## 1. 当前状态

- 已接入 `flutter_localizations` + `flutter gen-l10n`，支持 **English / 简体中文**。
- 语言设置：设置 › 通用 › 语言（跟随系统 / English / 简体中文），持久化在
  `settings.json` 的 `locale` 字段。
- 已迁移：语言设置行、启动错误页、Shell 导航、迷你播放条、播放控制、
  通用搜索/空状态/歌曲行/信息卡文案、整个设置域（设置 / 歌词设置 / 关于 /
  日志）。设置相关 core 枚举（主题色、歌词字号/强度/切句/对齐/模糊）的标签
  已移到 `lib/l10n/enum_labels.dart`。
- **仍为硬编码中文**：音乐库 / 专辑 / 歌手 / 播放列表 / 播放页 / 队列 / 歌词页，
  以及睡眠定时按钮。迁移按 `docs/TODO.md` 的后续阶段分批进行。

## 2. 目录与生成

```
l10n.yaml
lib/l10n/app_en.arb                 # 模板（英文，缺 key 会报错）
lib/l10n/app_zh.arb                 # 简体中文翻译
lib/l10n/app_localizations*.dart    # gen-l10n 生成，随仓库提交
lib/l10n/l10n.dart                  # context.l10n 扩展
```

- `template-arb-file` 是 `app_en.arb`：新增 key 必须先写英文模板，再补中文。
- 生成物提交进仓库（与 `database.g.dart` 的既有做法一致），保证 CI 跑测试时
  不依赖额外的生成步骤。
- 改完 ARB 运行：

```bash
flutter gen-l10n
```

CI / 提交前应确认生成物与 ARB 一致（`flutter gen-l10n` 后 `git diff --exit-code lib/l10n`）。

⸻

## 3. 使用

Widget 内：

```dart
import '../../l10n/l10n.dart';

Text(context.l10n.settingsLanguageTitle)
```

新增文案：

1. 在 `app_en.arb` 加 key 与 `description`（给译者/未来自己的上下文）；
2. 在 `app_zh.arb` 加同名翻译；
3. `flutter gen-l10n`；
4. 代码里用 `context.l10n.<key>`。

约定：

- key 用点分层级：`nav.library`、`settings.language.title`、`playlist.delete.confirm`；
- 带数量的一律用 ICU plural：`{count, plural, =0{...} =1{...} other{...}}`；
- 枚举的展示文案不要放回 `core/`：core 枚举的映射放 `lib/l10n`，
  feature 枚举就近放对应 feature（如 `features/shell/shell_l10n.dart`）。

### 布局注意

英文标签普遍比中文长，固定高度行（72px）容易溢出：

- 副标题统一 `maxLines: 1` + `overflow: ellipsis`；
- `SegmentedButton` 放在 `Flexible` 里，必要时用
  `ConstrainedBox(maxWidth: …) + FittedBox(scaleDown)` 等比缩小；
- `test/l10n_test.dart` 会在 1000×800 下渲染英文设置页 / 歌词设置页，
  溢出会直接让测试失败。

## 4. 语言解析与回退

- `AppSettings.locale`：`'system'` / `'en'` / `'zh'`；未知值（旧配置、手改文件）
  一律回退 `'system'`（见 `lib/core/utils/app_locale.dart`）。
- `MaterialApp.locale`：`'system'` → null（交给系统）；`supportedLocales` 顺序由
  `l10n.yaml` 的 `preferred-supported-locales: [en]` 决定，**非中文系统回退英文**。
- `isChineseUiLocale()`：应用内语言是否为中文。歌词中文翻译副行只在此为真时显示；
  语言切换后由 `LyricsViewModel.refreshLocaleDependentContent()` 重新解析当前歌词。

## 5. 测试

- Widget 测试：用 `test/helpers/l10n.dart` 的 `localizedApp(...)`，默认中文；
  验证英文时传 `locale: const Locale('en')`。裸 `MaterialApp` 没有
  `AppLocalizations`，`context.l10n` 会抛错。
- 纯 Dart 测试：用 `loadL10n(Locale('en'))` 取文案，不依赖 `BuildContext`。
- 新测试至少覆盖：ARB 文案、语言持久化 / 未知值回退、语言切换后的界面文案。

## 6. 边界

- **日志保持英文**（`docs/ErrorHandling.md`）：`AppLogger` 消息不翻译。
- 用户数据（歌名、歌手、播放列表名、歌词）不翻译。
- 服务层不要长期持有界面文案：播放错误、睡眠定时提示等应返回语义化类型，
  由 `app.dart` / 页面本地化（后续迁移按此方向）。
- **macOS 原生菜单目前跟随系统语言**：`AppDelegate.swift` 用
  `NSLocalizedString` 读取 `en.lproj` / `zh-Hans.lproj`，`MaterialApp.locale`
  不会改变它。若系统中文、应用内选英文，菜单仍为中文。同步方案（Dart 推
  `setLocale` + Swift 按语言加载 bundle 并重建菜单）记录在 `docs/TODO.md`，
  尚未实现。
- 品牌名 `0x4D` 与各平台窗口/应用名不翻译。
